# EBV Scan für Windows

Native Windows-Version mit PDF-Import, Windows-OCR, EBV-Auswertung für Boden, Bauschutt und Gleisschotter, Gegenüberstellung zur DepV Anhang 3 Tabelle 2 Spalte 5 (DK 0), Druckfunktion und Zurücksetzen für die nächste Bewertung.

Der GitHub-Workflow erzeugt eine selbständige 64-Bit-Datei `EBV Scan.exe`, für die auf dem Ziel-PC keine zusätzliche .NET-Installation erforderlich ist.
